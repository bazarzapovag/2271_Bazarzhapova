### Задание 2 **(2)**
*Напишите функцию* **sublist** для решения следующей задачи.*

*На вход функции поступает список или кортеж и набор номеров позиций.
Функция должна составить и вернуть список из элементов, которые
находятся на этих позициях. Примеры работы приводятся ниже. Работа функции должна строго им соответствовать.*

```
>>> lst = [ 'Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
>>> sublist(lst, 0, 2, 5)
['Anna', 'Clara', 'Flora']
>>> sublist (lst)
[]
>>> sublist(lst, 0, 1, 2, 3, 4, 5)
['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```
```
def sublist(seq, *index):
    return [seq[i] for i in index]
```
* seq принимает исходный список или кортеж
* *index собирает все переданные номера позиций в кортеж. Благодаря звёздочке функция может принимать любое количество индексов
* Внутри функции используется списочное включение: для каждого индекса i из index берется элемент seq[i]
* Функция одинаково работает со списками и кортежами т.к. используется обычное индексирование seq[i]
* Если позиции не переданы то index  пустой кортеж

### Задание 6 **(2)**

*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

```
def generator(n):
    while True:
        yield n
        if n == 1:
            return
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
```
* gen — функция-генератор, потому что содержит yield
* Сначала выдаётся текущее число n
* первое if: Если n == 1 то последовательность заканчивается return
* второе if: Если n чётное то следующее число равно n // 2
* else: Если n нечётное то следующее число равно 3 * n +1
* с помощью yield числа вычисляются по одному при каждом обращении к генератору

*Напишите генератор, который для заданной последовательности*
**seq** *будет задавать последовательность из каждого второго элемента* **seq**.

```

    ...
```
*Ниже приведены примеры использования генератра.*
```
>>> print (*every_other([10, 20, 30, 40, 50]))
10 30 50
>>> print(*every_other(range(10)))
0 2 4 6 8
>>> print(*every_other(iter(range(10))))
0 2 4 6 8
>>> print(sum(every_other(map(int, input().split()))))

```
```
def every_other(seq):
    for index, i in enumerate(seq):
        if index % 2 == 0:
            yield i
```
* enumerate(seq) перебирает элементы seq и одновременно нумерует их
* if i % 2 == 0 пропускает только элементы с чёт индексами так получается как "каждый второй"
* yield превращает функцию в генератор
