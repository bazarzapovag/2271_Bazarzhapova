### Задание 5 **(2)**

*Напишите программу на С++, которая прочитает натуральное число* **n**, *создаст вектор
из* **n** *элементов, прочитает значения элементов, добавит последний элемент вектора к каждому элементу 
(в том числе и к последнему), найдет и выведет количество положительных и отрицательных элементов вектора
после изменения. Из циклов в программе можно использовать только циклы по коллекции.*
```
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;

    std::vector<int> vec(n);
    for (int& v : vec) {
        std::cin >> v;
    }

    int last = vec.back();
    for (int& v : vec) {
        v += last;
    }

    int pol = 0;
    int otr = 0;
    for (int v : vec) {
        if (v > 0) {
            pol++;
        } else if (v < 0) {
            otr++;
        }
    }

    std::cout << pol << " " << otr << std::endl;
    return 0;
}
```
std::vector<int> vec(n); создаёт вектор из n элементов.

for (int& v : vec) std::cin >> v;  чтение значений

ссылка int& нужна, чтобы записать прочитанное в элементы вектора.

int last = vec.back(); это последний элемент до изменения 

for (int& v : vec) v += last; добавляем последний элемент к каждому

Второй цикл for (int v : vec) (v < 0) и (v > 0) подсчитывает положительные и отрицательные элементы

### Задание 6 **(3)**

*Представим, что в некотором будущем стандарте* **С++** *появится конструкция*
```
forc(i, from, to)
```
*которая будет раскрываться в следующий код.*
```
{
   int __i = from, __n=to;
   for(const int &i= __i; i < __n; __i++) {
      ...
   }
}
```
*Чем эта конструкция отличается от стандартного цикла* **for**? *Укажите два основных различия.
Напишите программы для демонстрации этих различий.*
1. В обычном for (int i = from; i < to; i++) переменная **i** обычная изменяемая переменная, её можно менять в теле цикла. В forc(i, from, to) переменная объявлена как const int &i это константная ссылка, её нельзя изменять в теле и компилятор выдаст ошибку и она связана с внутренней переменной **_i**
2. В стандартном цикле for (int i = 0; i < n.size(); i++) условие i < n.size() проверяется на каждой итерации, и если v меняется в теле то число итераций тоже меняется. В forc значения from и to вычисляются один раз и сохраняются в __i и __n. переменные __i, __n и i находятся в отдельном блоке они не видны после цикла и не конфликтуют с внешними именами
